# voxprobe

Pure Dart Global Illumination light-probe library: L2 (9-band RGB) Spherical Harmonics directional & hemispherical light baking, Kuhn 5-tetrahedra 3D volume localization, occlusion leak filtering, and flat 27-float GPU uniform packing.
